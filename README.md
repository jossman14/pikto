# Pikto — Bikin Gambar Keren

Landing page statis untuk jasa edit foto "Pikto": mengubah foto biasa menjadi karya bergaya (misalnya *watercolor painting*) yang bisa dijadikan hadiah.

## Isi Halaman
- Beranda (penawaran jasa)
- Galeri contoh hasil (sebelum/sesudah)
- Kontak

## Tech Stack
HTML, Bootstrap 4, MDBootstrap, jQuery, Font Awesome.

## Struktur
- `index.html` — halaman utama
- `css/`, `js/`, `scss/`, `font/` — aset MDBootstrap/Bootstrap
- `img/` — gambar latar dan galeri (`basic/`, `hasil/`)

## Menjalankan
Buka `index.html` langsung di browser, atau sajikan dengan server statis (mis. `npx serve .`).
